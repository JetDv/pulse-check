# 4Runner Gauges

Android OBD-II gauge app for a Dasaita head unit (Android 13).

- **Demo** button: fake data, no adapter needed.
- **Connect**: pick a paired Bluetooth ELM327-style adapter (vLinker, OBDLink).
- **Codes**: read stored + pending trouble codes, with an option to clear.

Every push builds an APK. Download the newest one from:
`https://github.com/<you>/<repo>/releases/latest/download/obd-gauges.apk`

Add or change gauges in the `GAUGES` list at the top of `MainActivity.kt`.
